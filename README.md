# GlowCrafts

Модульный плагин кастомных крафтов для серверов Paper / Folia (Java 21). Позволяет создавать и настраивать кастомные рецепты для верстака (Shaped / Shapeless), наковальни и печи через удобное внутриигровое GUI без ручного редактирования файлов конфигурации.

## Возможности

- Рецепты верстака (сетка 3x3 и бесформенный крафт)
- Рецепты наковальни (комбинации предметов, кастомный ремонт, стоимость в уровнях опыта)
- Рецепты печи (плавка с настройкой времени и опыта)
- Внутриигровой визуальный GUI-редактор для создания, редактирования и удаления рецептов
- Поддержка предметов с кастомными NBT, ItemMeta, зачарованиями, названиями и лором
- Опциональные условия: права доступа, стоимость в опыте, денежная стоимость через Vault
- Режим проверки точного совпадения предметов (NBT/Meta) либо совпадения по типу материала
- Сохранение и загрузка конфигураций в формате YAML с сохранением всех метаданных предметов

## Команды и права

- `/glowcrafts` (алиас `/gc`) — открыть главное меню плагина (`glowcrafts.admin`)
- `/glowcrafts create <shaped|shapeless|anvil|furnace>` — открыть редактор рецепта выбранного типа (`glowcrafts.admin.create`)
- `/glowcrafts list` — открыть список созданных рецептов (`glowcrafts.admin.list`)
- `/glowcrafts reload` — перезагрузить конфигурации и рецепты (`glowcrafts.admin.reload`)

## Сборка

```bash
mvn clean package
```
Готовый jar-файл находится в директории `target/`.
